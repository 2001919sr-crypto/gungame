# GunGame 設計書（お手本：Arrow a Row）

作成日: 2026-10-05
対象: このプロジェクトの作者（Claude Code 初心者）と、実装を担当する Claude Code

---

## 1. コンセプト（1行で）

**「左右に動くだけ。ゲートを選んで弾を増やし、ボスを倒す」縦スクロール・オートシューター。**

Arrow a Row の「矢」を「銃の弾」に置き換えたもの。
プレイヤーは勝手に前進し、勝手に撃つ。やることは **左右移動** だけ。

### お手本（Arrow a Row）から真似する要素
| 要素 | 内容 |
|---|---|
| 操作 | 左右移動のみ。射撃は自動 |
| ゲート | 2択のパネルを通過すると弾が強化（または弱体化）される |
| 成長の快感 | 弾がどんどん増えて画面を埋める |
| 構成 | 雑魚ウェーブ → 中ボス → ラスボス（2段階）→ クリア |
| 周回要素 | コインで恒久アップグレード（次の挑戦が少し楽になる） |

### 最初は真似しないもの（後回し）
- ペット・飛剣などの追加ユニット
- ガチャ・装備
- エンドレスモード、ランキング
- 広告・課金

## 2. プレイ体験の流れ（ゲームループ）

```
タイトル → [プレイ 60〜90秒] → リザルト（コイン獲得） → 強化ショップ → タイトル
```

1 回のプレイ（1ラン）は **約 60〜90 秒**。短いのが大事。
ブログや動画で「1 回見せる」のに丁度いい長さ。

### 1 ランの構成（2026-10-06 決定）
**プレイヤーが死ぬまで続く。** 次の 1 周を繰り返し、周を重ねるごとに敵が強くなる。

```
雑魚 → 中ボス → 雑魚 → 中ボス → 雑魚 → 大ボス → (次の周へ) 雑魚 → 中ボス → …
```

- スコアは **進んだ距離**（1 秒 = 10m。ボス戦の間も増える）。「何周目のどこまで行けたか」も一緒に記録する

### 画面（2026-10-07 決定）
- **タイトル画面**: ゲーム名・スタート・自己ベスト（距離と到達地点）・ショップ（Step 5 までは「準備中」）
- **リザルト画面**: スコア（距離）・自己ベスト・到達地点・時間・コイン・倒した敵の数・倒したボスの数・取ったアイテムの種類と数・ボスのご褒美。ボタンは「もう一度」「タイトルへ」
- 一時停止の「終了」は「タイトルへ」に変更
- 自己ベストは user://save.json に保存する（Step 5 でコインも同じファイルに入れる）
- 中ボスは「+10」、大ボスは「×2」の 3 択ご褒美を落とす（3.8）

### 旧案: 1 ラン内の構成（ステージ 1 の例。参考として残す）
| 区間 | 時間 | 内容 |
|---|---|---|
| ウェーブ 1 | 0〜15 秒 | 弱い敵のみ。ゲート 2 回 |
| ウェーブ 2 | 15〜35 秒 | タンク敵が混ざる。ゲート 3 回 |
| ウェーブ 3 | 35〜55 秒 | 撃ってくる敵が混ざる。ゲート 3 回 |
| ボス | 55 秒〜 | 2 段階。倒せばクリア |

## 3. ゲームルール詳細

### 3.1 プレイヤー
- 画面下部中央にいる。前進は背景スクロールで表現（自分は縦位置固定）
- 操作: **左右タップ**。画面の左半分を押している間は左へ、右半分は右へ動く。PC では ← → キー
  - 入力処理は `scripts/input.gd` の 1 ファイルに閉じ込める。後で「ドラッグ追従」に変えたい時はこのファイルだけ直す
- 一定間隔で自動射撃（上方向）
- HP あり。最初は 100 で **上限なし**。敵に接触、または敵弾に当たると減少。0 でゲームオーバー
- **回復は吸収だけ**: 敵に与えたダメージの 5% が体力に戻る（とどめで余った分は数えない）。中ボスのご褒美「吸収 +5%」で伸ばせる（2026-10-07 決定）

### 3.2 弾（成長の中心）
弾の状態は以下の **数値の組** で表す。ゲートはこの数値を書き換えるだけ。

| パラメータ | 初期値 | 説明 |
|---|---|---|
| `count` | 1 | 同時に撃つ弾の数（横に並ぶ） |
| `damage` | 10 | 1 発のダメージ |
| `fireRate` | 2 発/秒 | 連射速度 |
| `pierce` | 0 | 貫通できる敵の数 |
| `size` | 1.0 | 弾の大きさ倍率 |
| `spread` | false | 扇状に広がって撃つか |

> 設計のポイント: 「弾の種類」を増やすのではなく「数値」を増やす。
> こうすると新しいゲートを 1 行追加するだけで作れる。

### 3.3 ゲート（2択パネル）
- 画面の左半分・右半分に **1 枚ずつ** 流れてくる。必ずどちらか一方を通過する
- 通過した瞬間に効果が適用される
- 良いゲート（緑）と悪いゲート（赤）がある。「良い vs 良い」「良い vs 悪い」の組み合わせで出す

#### ゲート一覧（MVP）
| 表示 | 効果 | 色 | 出現率 |
|---|---|---|---|
| +1 弾 | `count += 1` | 緑 | 高 |
| +ダメージ | `damage += 5` | 緑 | 高 |
| 連射 UP | `fireRate += 0.5` | 緑 | 中 |
| 貫通 | `pierce += 1` | 緑 | 中 |
| 巨大弾 | `size += 0.3` | 緑 | 低 |
| -1 弾 | `count -= 1`（最低 1） | 赤 | 中 |
| 連射 DOWN | `fireRate -= 0.5`（最低 1） | 赤 | 中 |

### 3.4 敵（MVP は 3 種 + ボス）
敵は **左・中央・右の 3 列だけ** に出る（2026-10-06 決定）。敵は **列の幅いっぱい**（幅 140〜160px）の四角。列と列のすき間には逃げられず、よけるには隣の列へ移る（2026-10-07 決定）。

**跳弾は廃止**（2026-10-07 決定）。ゲートは 弾数 +1 / 貫通 +1 / 巨大弾 / 弾数 -1 / 射程 -2 の 5 種類

| 名前 | HP | 速度 | 特徴 |
|---|---|---|---|
| ウォーカー | 20 | 普通 | 下に向かって歩くだけ |
| タンク | 80 | 遅い | 硬い。貫通・ダメージの価値を教える |
| シューター | 30 | 普通 | 止まって弾を 1 発撃ってくる |
| **中ボス** | 400 | 雑魚と同じ | 横幅いっぱい。下記 |
| **大ボス** | 4000 | 画面上部 → 速く降りる | 横幅いっぱい。下記 2 段階 |

#### 周回とボス（2026-10-07 決定）
- 1 周 = **雑魚 30 秒 → 中ボス → 雑魚 30 秒 → 中ボス → 雑魚 30 秒 → 大ボス**。死ぬまで繰り返す
- 雑魚区間が終わると敵が出なくなり、「中ボス出現!」の予告の後にボスが上から降りてくる。ボス戦の間はゲート・アイテムは流れてこない
- ボスは **横幅いっぱい** で避けられない。**着かれる前に倒しきる** のが目的（2026-10-07 改訂）
- **中ボス**: 雑魚と同じく画面の上の外で生まれ、雑魚と同じ速さで降りてくる。弾は撃たない。射程が長いほど早く削り始められる
- **大ボス**（2 段階）
  - 第 1 段階: 画面上部に居座り扇形に 5 発ばらまく（弾はよけられる）。射程が短い銃でも届くよう、プレイヤーの射程に合わせて少し下がってくる
  - 第 2 段階（体力 50% 以下）: 赤くなり、速く降りてくる
- **着かれたら**: ボスの残り体力の 20% のダメージを受ける（無敵時間中でも受ける）。ボスは消え、ご褒美とコインはもらえない。区間は次へ進み、敵の体力の倍率も上がる
- **周ごとの強くなり方**: 中ボスを倒すたびに敵の体力 ×1.2、大ボスを倒すたびに ×1.5（掛け算で重なる。ボスにも同じ倍率）。1 周目の雑魚 1 が ×1.0 → 2 周目の始めは ×2.16 → 3 周目の始めは約 ×4.7
- ボスを倒すとコイン（中ボス 10 / 大ボス 30）と 3 択のご褒美（3.8）

**敵の弾は撃ち落とせない（決定）。** 防御手段は「避ける」だけ。弾幕をよける緊張感を残すための作者の判断

### 3.5 周回（メタ）要素
- ラン終了時、倒した敵の数に応じてコイン獲得
- ショップで恒久強化を購入（最初は 3 種だけ）

| 強化 | 効果 | 価格（Lv1） |
|---|---|---|
| 基礎ダメージ | 初期 `damage` +2 / Lv | 50 |
| 基礎 HP | 初期 HP +20 / Lv | 50 |
| 開始弾数 | 初期 `count` +1（最大 Lv3） | 200 |

保存先: 端末の中のファイル（Godot の `user://` に JSON）。サーバー不要

#### コインの流れ（決定）
- **入手**: ゲームを遊ぶともらえる。倒した敵の数 + クリアボーナス。課金では買えない
- **使い道**: ① 上の恒久強化 ② 追加の銃の解放（3.6） ③ **倍速再生の解放**

#### 倍速再生（決定）
- 慣れた人向けに、ゲーム全体の速さを 1.5 倍 / 2 倍にできる。買い切りでコインで解放し、以後はボタンで切り替え
- Godot では `Engine.time_scale` を変えるだけで実現できる（敵も弾もゲートも一緒に速くなる）
- 段階（1.5× / 2× / 3×）と価格は後で調整

#### 収益モデル（決定: 広告。課金なし）
- 候補 1: リザルト画面の「動画を見てコイン 2 倍」（プレイヤーが選んで見るリワード広告）
- 候補 2: ゲームオーバー時の「動画を見てその場で復活」
- 強制表示のバナーや割り込み広告は最初は入れない（遊びの邪魔になり評価が下がる）
- 実装は Step 6 以降（AdMob の非公式プラグイン）。広告を入れると Google Play の「広告の有無」と「データ セーフティ」の申告を更新する必要がある（[PUBLISH_GUIDE.md](PUBLISH_GUIDE.md) 4-5）

### 3.6 開始時の銃選び（3 種）
ランの最初に落ちてくる箱を取ると 3 択画面が出て銃を選ぶ（本家の「賞を選んでください」に相当）。**ゲーム中は交換できない。** 見た目はおもちゃの銃。

| 銃 | 初期の弾 | 連射 | 1 発の威力 | 特徴 | 向く人 |
|---|---|---|---|---|---|
| ハンドガン | 1 | 普通 | 普通 | 素直。全部のゲートが 1 丁に効く | 初めての人 |
| ショットガン | 3（扇状） | 遅い | 高い | 弾が広がるが届く距離が短い。近づく勇気が要る。「+1 弾」で扇が広がる | 爽快感を求める人 |
| 二丁拳銃 | 1 + 1 | 普通 | 低め | 左の銃は左のゲート、右の銃は右のゲートで育つ。片方に極振りするか両方育てるか | やりこむ人 |

- MVP ではこの 3 本が最初から選べる
- 実装上は「弾のパラメータの組」を銃ごとに持つだけ。二丁拳銃は組を 2 つ持ち、ゲートの左右で振り分ける
- **銃は設定データとして追加できる作りにする**（`config.gd` に 1 ブロック足せば 1 本増える）。下の追加分のため

#### 追加予定の銃（MVP の後。コインで解放する想定）

| 銃 | 一言で | 特徴 | 実装の重さ |
|---|---|---|---|
| スナイパーライフル | 遠くから一撃 | 連射が遅く威力が非常に高い。最初から貫通あり。敵を一直線に並べて撃ち抜く | 低（数値だけ） |
| バズーカ | ドカンと範囲攻撃 | 連射が遅く、着弾で周りの敵もまとめて吹き飛ばす。集団に強く、1 体のボスにはやや弱い | 中（爆発の処理を足す） |
| マシンガン | 弾幕で押す | 連射が速く威力が低い。弾が多いので画面内の弾の上限に注意 | 低（数値だけ） |

- 「新しい銃を解放する」ことがコインの使い道になり、「もう 1 回遊ぶ理由」になる
- 1 本足すごとにブログと動画のネタになる（「バズーカ追加してみた」）

### 3.7 デイリーチャレンジ（今日のシード）
- **通常モード**: 毎回ランダムな展開（これが基本）
- **デイリー**: その日の日付をシード（ランダムの出発点になる数）にして、全員が同じゲート配置・同じ敵の順番で遊ぶ。スコアを SNS で比べられる
- 仕組みは「シード = 日付」の 1 行。タイトル画面に「今日のチャレンジ」ボタンを置く
- 結果を画像にして共有する機能は後回し（公開後）

### 3.8 アイテム（2026-10-06 改訂）
ゲートと役割を分ける。**ゲート = 弾の「形」を変える 2 択。アイテム = 「数値」を上げる、取るかどうか自由なもの。**

#### 敵が落とすアイテム（本家と同じ「+1」単位）（2026-10-07 改訂）
| アイテム | 効果 | 備考 |
|---|---|---|
| 威力 +1 | 弾のダメージ +1 | |
| 射程 +1 | 弾の届く距離 +1 段階 | 下の「射程」を参照 |
| 弾速 +1 | 弾の速さ +1 段階 | |
| 連射 +1 | 連射 +1 段階 | |
| コイン | 周回用のコイン | |

- **すべての敵が倒されると必ず 1 個落とす**。道中に流れてくるアイテムはない。倒した場所から下に流れてくる。触れたら取れる
- ハート（回復アイテム）は廃止。回復は吸収だけ（3.1）
- 効果はそのランの間だけ。全部の銃に効く（二丁拳銃は両方）

#### 射程（すべての銃にある）
- どの銃も弾の届く距離が決まっている。最初は画面の上端まで届かない
- **射程を伸ばすと、画面の上の外にいる「これから来る敵」を、見える前に倒せる**
- そのため敵は画面の上の外で生まれ、見えない所から歩いてくる

#### ボスが落とすアイテム（3 択画面で 1 つ選ぶ。銃選びと同じ画面）
- **中ボス**: 威力 / 射程 / 弾速 / 連射 / 吸収 +5% の中から **毎回ランダムに 3 つ**。強さは「道中アイテム +1 の 10 個分」（威力 +10、射程 +400px、連射 +2.5 回/秒 など。項目ごとに強さをそろえるため）（2026-10-07 決定）
- **大ボス**: 威力 ×2 / 連射 ×2 / 弾数 ×2 の 3 つ
- ×2 は大ボスだけの特別なご褒美。金ゲート「弾数 ×2」は廃止（2026-10-06）

#### 弾が増えすぎた時（2026-10-07 決定）
- 1 回に撃つ弾は 1 丁あたり最大 40 発まで。それを超えた分は **1 発の威力に上乗せ** する（弾数 ×2 は必ず攻撃力 2 倍になる。弾も少し大きくなる）
- 連射が速すぎて 1 コマに 2 回以上撃つ時も、まとめて 1 回にして威力に上乗せする
- 画面内の弾の上限は 1000 発（安全柵）。Web 公開後に実機のスマホで測り、カクつかない一番大きい数に合わせる
- もっと多く見せたくなったら、Step 7 で弾の作り方を軽い方式（まとめて描画・計算だけで当たり判定）に変える。それでもスマホでは数千発が目安。3 万発は無理

### 3.9 ペット（決定。公開前に実装）
自動で戦う仲間。**コインで解放し、ランの前に 1 体だけ連れていく。**

| ペット | 動き | 攻撃 | 性格 |
|---|---|---|---|
| ドローン | プレイヤーの斜め上をふわふわ追従 | 弱いレーザーを速いテンポで。一番近い敵を自動で狙う | 手数で稼ぐ |
| ミニ戦車 | プレイヤーの横を少し遅れて追従 | 重い砲弾をゆっくり。1 発が強い | 一撃で稼ぐ |

- ペットの弾は銃と同じ「弾のパラメータの組」（`weapon_state.gd`）で作る
- ゲートはペットに効かない。ペット自身の強化はコインでショップから
- **ペットは盾にならない**。敵の弾はペットを通り抜ける（「敵の攻撃は防げない」方針と一貫）

## 4. 技術選定（2026-10-05 決定）

| 項目 | 選択 | 理由 |
|---|---|---|
| 開発機 | **Windows**（Mac は iPhone 向け書き出しの時だけ使う） | 普段使いの PC。Godot はどちらでも同じに動く |
| エンジン | **Godot 4.7.2**（2026-10-05 時点の最新安定版） | 無料。プロジェクト全体がテキストなので Claude Code がほぼ全部書ける。起動が軽い |
| 言語 | **GDScript** | Python に似て読みやすい。C# は Web 書き出しが動かないので使わない |
| レンダラー | **Compatibility（gl_compatibility）** | Web 書き出しはこれしか動かない。スマホでも軽い |
| 画面 | 縦画面固定。基準解像度 540×960。端末の縦横比に合わせて上下を広げる（stretch: canvas_items / expand） | スマホ前提 |
| 操作 | **左右タップ**（画面の左半分を押している間は左へ、右半分は右へ）。PC は ← → キー | 単純で誤操作が少ない。`input.gd` に閉じ込め、後で「ドラッグ追従」に差し替え可能 |
| 絵 | **軽さ優先・おもちゃ風**。小さなドット絵（キャラ 32px 前後、弾 8px 前後）か図形。明るい色、丸みのある形。最初は図形、後から無料素材か AI 生成で差し替え | スマホで 60fps を出すため。おもちゃ風は図形だけでも雰囲気が出る |
| 音 | 後回し | |
| 配信の順番 | **1. Web 版（無料・審査なし） → 2. Google Play（25 ドル一度だけ） → 3. App Store（年間 99 ドル、手応えが出てから）** | 「嫌な費用」を最後まで先送りする |
| 広告 | 後回し（AdMob の非公式プラグイン） | Step 6 以降で検討 |

### 軽さの方針（スマホで快適に動かすため）
- 目標 60fps、最低 30fps。開発中は画面の隅に FPS を表示しておく
- 画像は 1 枚のスプライトシートにまとめ、テクスチャフィルタは Nearest（ドット絵がぼやけない）
- 画面内の弾は最大 1000 発で打ち止め。1 回に撃つ弾は 1 丁 40 発まで、超えた分は威力に変える（3.8）
- パーティクルや影などの飾りは最後に、効果を測ってから足す
- Web 版の初回読み込みは 10MB 前後になる。画像・音を小さく保つ

### Godot で進める上での注意（忘れがちな点）
- Web 書き出しは **Thread Support を OFF** にする。そうしないと iPhone の Safari で動かず、GitHub Pages でも特別な設定が必要になる
- Google Play 用の書き出しには Android SDK と Java の準備が一度だけ必要（約 1 時間）
- Google Play は 2026-08-31 以降、新規アプリに Android 16（API 36）対応を要求。Godot 4.7 の既定値で満たせる
- iPhone 向けの書き出しは Mac が必要。所有しているので問題なし。開発中は無料の Apple ID で自分の iPhone に入れて試せる
- Google Play の新規個人アカウントは、本番公開前に 12 人以上のテスターで 14 日間のクローズドテストが必要
- 日本語を画面に出すには日本語フォントを同梱する必要がある（Web 版は端末のフォントを使えず、四角に化ける）。Step 4 の UI で対応。開発中のデバッグ表示は英数字で済ませる
- 公開までの具体的な手順は [PUBLISH_GUIDE.md](PUBLISH_GUIDE.md) にまとめた

### 検討して選ばなかったもの
- **素の JavaScript + Canvas**: 最速だがアプリストアに出すには別途アプリ化が必要。ストア配信を目指すと決めたため不採用
- **Unity**: エディタでの手作業が多く Claude Code に任せられる範囲が狭い。Web 書き出しも重い

## 6. 開発ステップ（MVP を 5 段階で）

各ステップは「ブラウザで開いて動く」状態で終わること。終わったら必ず 1 回遊ぶ。

| Step | 作るもの | 完成の判定 | 想定 |
|---|---|---|---|
| **1** ✅ | 画面・ゲームループ・左右タップ移動・自動射撃・銃 3 種の数値 | 弾が上に飛ぶ。1/2/3 キーで銃が替わる | 1 日目 |
| **2** ✅ | 敵 3 種の出現・当たり判定・HP・ゲームオーバー | 敵を撃って倒せる。接触で死ぬ | 2 日目 |
| **3** ✅ | ゲート（2択）・道中のアイテム（6 種）・射程と画面外の敵・タンクのドロップ | 弾が増えて気持ちいい。アイテムを取りに行く | 完了 2026-10-06 |
| **4** ✅ | 周回（雑魚・中ボス・大ボス）・ボスのご褒美 3 択・タイトル画面・リザルト・自己ベスト保存 | 1 ランが最初から最後まで遊べる | 完了 2026-10-07 |
| **5** | コイン・ショップ（恒久強化・ペット解放）・セーブ | 「もう 1 回」が生まれる | 5 日目 |
| **6** | ペット 2 体（ドローン・ミニ戦車） | 仲間が一緒に撃つ | 6〜7 日目 |

## 8. 決定事項と未決事項

### 決定済み（2026-10-05）
1. **スマホ向け**に作る（縦画面）
2. **エンジンは Godot 4.7.2、言語は GDScript、レンダラーは Compatibility**
3. **配信順**: Web → Google Play → App Store
4. **テーマ**: 矢ではなく「銃」（フォルダ名 gungame に合わせた）
5. **進め方**: 実装を急がず、作者と対話して手法を決めてから作る
6. **開発機は Windows**
7. **操作は左右タップ**（後でドラッグ追従に変更可能。`input.gd` だけ直す）
8. **絵は軽さ優先**（小さなドット絵か図形）
9. 公開までの手順は [PUBLISH_GUIDE.md](PUBLISH_GUIDE.md) に従う
10. **GitHub リポジトリは公開（public）**。無料の GitHub Pages を使うため。鍵・パスワード類は絶対にコミットしない
11. **タイトルは仮に「GUNGAME」**。正式名はゲームの「ひとひねり」が決まってから
13. **開始時に 3 種の銃から選ぶ**: ハンドガン / ショットガン / 二丁拳銃
15. **追加の銃を後から足す**（スナイパーライフル、バズーカ、マシンガン）。銃は設定データで増やせる作りにする
16. **コインはプレイで獲得**。使い道は恒久強化・追加の銃の解放・倍速再生の解放
17. **収益は広告モデル（課金なし）**。リワード広告を候補に、実装は公開後
18. **敵の弾は撃ち落とせない**。防御は回避のみ
19. **アイテム**: すべての敵が倒されると必ず落とす「+1」単位のアイテム（威力・射程・弾速・連射・コイン）。回復は吸収だけで体力の上限なし。中ボスは +10 系、大ボスは ×2 の 3 択。効果はそのランの間だけ（2026-10-07 改訂）
21. **射程はすべての銃にある**。伸ばすと画面外の奥の敵を倒せる。敵は画面の上の外で生まれる
22. **敵は左・中央・右の 3 列だけに出る**。銃は最初の箱の 3 択で決まり、ゲーム中は交換できない
23. **死ぬまで続く**。1 周 = 雑魚 → 中ボス → 雑魚 → 中ボス → 雑魚 → 大ボス。周ごとに強くなる
24. **ボスのご褒美は 3 択**。中ボスは +10、大ボスは ×2。金ゲートは廃止
20. **ペットは公開前に実装**（Step 6）。コインで解放し、ランの前に 1 体連れていく。盾にはならない
14. **通常はランダム。デイリーチャレンジは日付シード**で全員同じステージ
12. **銃の雰囲気は「おもちゃ」**（NERF 風）。リアルさは追求しない。弾はスポンジのダーツ、敵はおもちゃのロボットやブロックのイメージ。明るい色。血や生々しい表現なし → ストアの年齢制限が最も緩くなる

## 9. 用語メモ（初心者向け）

- **ゲームループ**: 1 秒間に 60 回「状態を更新して → 描く」を繰り返す仕組み。すべてのゲームの心臓
- **当たり判定**: 2 つの物体が触れたか調べる計算。このゲームは全部「丸と丸」で判定して単純化
- **ステートマシン**: 「今はタイトル画面」「今はプレイ中」のように状態を 1 つ持ち、状態ごとに処理を切り替える方法
- **user://**: Godot が用意するセーブ用の場所。端末の中にファイルとして保存するのでサーバーが要らない
- **シード**: ゲームのランダムの出発点になる数。同じシードなら毎回同じ展開になる
- **MVP**: 最小限で遊べる版。まずこれを作ってから飾りを足す
